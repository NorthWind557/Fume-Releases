# Fume

Instalador e atualizações públicas do Fume para Windows x64.

- [Baixar a versão mais recente](https://github.com/NorthWind557/Fume-Releases/releases/latest)
- [Validação da versão 0.39.42](docs/VALIDACAO-0.39.42.md)
- [Atualizar o servidor do J8](docs/ATUALIZAR-SERVIDOR-J8.md)

Para atualizar pelo aplicativo, abra **Ajuda → Verificar atualizações…**. O Fume baixa e verifica o instalador sem token do GitHub.

Em um PC novo, peça ao responsável pelo J8 o acesso ao Tailscale e os dados do servidor por um canal privado. Abra **Configurações → Conta**, informe o endereço HTTPS, use **Escolher certificado público…** e clique em **Testar e salvar servidor**.

A versão 0.39.42 reúne a instalação em Downloads, melhora GIFs e enquadramento do miniperfil e corrige a exibição de saldos e descrições na Biblioteca.

Este repositório contém a distribuição pública e os guias. As contas, senhas, bancos, sessões e chaves privadas dos usuários não são publicados aqui.
