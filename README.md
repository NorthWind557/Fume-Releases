# Fume

Instalador e atualizações públicas do Fume para Windows x64.

- [Baixar a versão mais recente](https://github.com/NorthWind557/Fume-Releases/releases/latest)
- [Validação da versão 0.39.40](docs/VALIDACAO-0.39.40.md)
- [Atualizar o servidor do J8](docs/ATUALIZAR-SERVIDOR-J8.md)

O aplicativo consulta a distribuição assinada e baixa atualizações sem token GitHub. Em um PC novo, o assistente orienta a conexão pelo Tailscale e o cadastro de usuário e senha. É necessário entrar também no aplicativo Tailscale do Windows; criar a conta no site não conecta o computador automaticamente.

A versão 0.39.40 amplia perfis, miniperfis e personalização; introduz a loja de pontos, carteiras GC/GP, carrinho, aquisições, devoluções e promoções administradas no servidor. Os créditos são virtuais e estão em fase de testes.

Este repositório contém a distribuição pública e os guias. As contas, senhas, bancos, sessões e chaves privadas dos usuários não são publicados aqui.
